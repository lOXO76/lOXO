Quick Start

三步接入，
三分钟跑通。

  1. 注册并登录

    注册一个 lOXO 账号，或直接 登录，查看余额与可用分组。

  2. 创建 API 密钥

    在「API 密钥」页面新建密钥并选择分组，点击「使用」即可生成各客户端的完整配置。

  3. 填入客户端

    把 Base URL 与密钥填进你常用的工具，开始调用；用量与费用随时可在控制台查看。

# macOS / Linux 终端
export ANTHROPIC_BASE_URL="https://loxo.cc"
export ANTHROPIC_AUTH_TOKEN="sk-你的密钥"

# 启动 Claude Code
claude
# ~/.codex/config.toml
model_provider = "OpenAI"

[model_providers.OpenAI]
name = "OpenAI"
base_url = "https://loxo.cc/v1"
wire_api = "responses"
requires_openai_auth = true

# ~/.codex/auth.json
{ "OPENAI_API_KEY": "sk-你的密钥" }
# macOS / Linux 终端
export GOOGLE_GEMINI_BASE_URL="https://loxo.cc"
export GEMINI_API_KEY="sk-你的密钥"

# 启动 Gemini CLI
gemini
# 查看当前密钥可用的模型
curl https://loxo.cc/v1/models \
  -H "Authorization: Bearer sk-你的密钥"

# 发起一次对话（OpenAI 兼容格式）
curl https://loxo.cc/v1/chat/completions \
  -H "Authorization: Bearer sk-你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"model":"模型名","messages":[{"role":"user","content":"你好"}]}'
完整配置（含 Windows / 模型参数）请在控制台 API 密钥 → 使用 中一键生成
